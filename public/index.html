/things/ 토픽에서 실제 기기 ID 후보를 찾습니다. 여러 토픽을 구독하는 앱일 수도 있으므로 확인 후 등록하세요.

TLS passthrough는 암호화 상태여서 ID를 읽을 수 없습니다. Bridge가 TLS를 해제하는 연결과 평문 MQTT를 탐지합니다.

기기 등록

Custom Firmware Build · DIV01

검증된 1630 원본으로 버전 문자열과 ESP8266 체크섬을 수정합니다. 먼저 Prepare / Retry DIV01 Firmware를 실행하세요.

인증서 검증 우회 패치입니다. Root CA는 별도 동봉 파일이며 펌웨어에 내장되거나 장치에서 신뢰되지 않습니다. 다른 모델은 지원하지 않으며, 사용자 지정 버전은 실제 장치 검증이 필요합니다.

호스트 변경은 HTTP URL 2곳과 독립 호스트명 1곳에 적용됩니다. 해당 DNS/IP가 Bridge를 가리키도록 설정하세요. CA 검증은 장치의 TLS 검증 우회를 해제하지 않습니다.

포트별 동작 설정

Bypass는 원본 dapt.iptime.org의 동일 포트로 TLS를 포함한 바이트를 그대로 전달합니다. Proxy는 지정한 서버로 전달합니다. Custom server는 입력한 고정 응답을 반환합니다. 모든 모드에서 접속·종료·전송량·오류를 기록합니다.

TLS 종료에는 Bridge 서버 인증서가 사용됩니다. 저장한 모드는 새 연결부터 적용되며 재시작 후에도 유지됩니다.
